# 🐾 Vet Controll

Sistema veterinário inteligente desenvolvido com foco em organização, praticidade e experiência do usuário.

---

## 🚀 Sobre o projeto

O **Vet Controll** é uma plataforma criada para facilitar a gestão de clínicas veterinárias, permitindo o controle de atendimentos, organização de pets, agendamentos e muito mais.

Nosso objetivo é eliminar a complexidade da gestão clínica, permitindo que o profissional foque no que realmente importa: **o cuidado com os animais**.

---

## 🎯 Funcionalidades

* 📋 Organização completa dos pets
* ⏱️ Agendamento de consultas
* 🔐 Segurança das informações
* 📊 Visualização de dados
* 🧑‍⚕️ Gestão de atendimentos
* 💻 Interface simples e intuitiva

---

## 🖥️ Tecnologias utilizadas
